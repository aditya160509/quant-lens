Studio workspace: the plan

One screen. Code is the centre. Everything else is a panel you open when you want it.

3. Strategy Tester (bottom) vs Report page

Strategy Tester drawer (quick, while you code)

  • Key stats: PnL, max DD, win %, profit factor, Sharpe
  • Equity / drawdown / buy and hold
  • List of trades (click a trade and the chart jumps there)
  • Settings: dates, capital, costs

Report page (full, after the strategy is done)

  • Performance: breakdown, periods, benchmark, growth and decline
  • Trades: distribution, streaks, time patterns, MAE/MFE
  • Tearsheet: monthly heatmap, underwater, rolling Sharpe
  • Robustness: Monte Carlo, walk-forward, parameter stability
  • Compare runs, certificate, export

Most of the maths is already built (devStats, Tearsheet, Robustness, Compare). The page gathers it.

4. Feel

  • Every panel opens, closes and resizes on one spring animation; no jumps.
  • Dividers are thin, rounded, and highlight on hover; the drag runs at 60 fps (no React re-render while dragging).
  • Panels are closed by default; View menu, shortcuts and the palette open them.
  • No SVG chart hacks; Vela (WebGL) draws everything chart-related.

5. Order of work

  1. foundation New panel system: resizable splits, animations, remembered layout. Fixes the "preview too short / resizing broken" issues.
  2. chart Vela in the chart panel, fed with our bars, trades, plots and paused bar. Mark B in the status bar.
  3. tester Strategy Tester drawer.
  4. script New ctx drawing calls + parameter Inputs form (Indie-style).
  5. report Full Report page.
  6. cleanup Remove the old engine and preview once nothing uses them (ask first).
