# PCA-V2 Frontend Review — Brutal, Bloomberg-Grade

Scope (read-only): `frontend/src/components/pca-v2/customPagePrimitives.jsx` (931 lines, incl. `PCA_OUTPUT_BOOKS` 11 books) + `frontend/src/components/pca-v2/registry.js` (190 lines, 11 features) + `frontend/src/app/labs/pca-v2/` (index + 11 feature pages + layout strip).
Standard: Bloomberg Terminal / TradingView / QuantConnect. Best-in-class refs: factoextra/PCAtools (scree/biplot), Riskfolio-Lib, PyPortfolioOpt, Bailey–Lopez de Prado RMT, Observable clustergrams.

## Score: 3.5 / 10

Why so low: **nothing on screen is real data.** Every chart and table renders `previewRows` — `Math.sin(seed+i)` synthetic filler (customPagePrimitives.jsx:210-245) — behind a workbench whose only action button reads "API pending" (customPagePrimitives.jsx:536). Copy buttons have no handlers (customPagePrimitives.jsx:561-562), the pie is hardcoded 72/28 (customPagePrimitives.jsx:233), the scree MP line is a flat 0.42 (customPagePrimitives.jsx:290), footers say "Ready for API key" (customPagePrimitives.jsx:566). This is a handsome prototype shell, not a product surface. It scores above 3 only because the output-book taxonomy (11 books, ~110 sections) is genuinely well-structured and the input-deck grouping is clean. Nothing here meets Bloomberg/TradingView data-integrity bar until the preview pipeline is replaced with live binding.

## Top 10 improvements by impact

1. **Bind real data; delete the sin() pipeline.** `previewRows` (customPagePrimitives.jsx:210-245), `StandardChart` (customPagePrimitives.jsx:271-336), `Heatmap` (customPagePrimitives.jsx:338-362), `DataTable` (customPagePrimitives.jsx:364-377), `MetricDeck` (customPagePrimitives.jsx:379-391), `Waterfall` (customPagePrimitives.jsx:393-410), `PieVisual` (customPagePrimitives.jsx:412-426) all consume synthetic rows. `PcaV2Workbench` (customPagePrimitives.jsx:521-526) takes `sections` but never fetches. Shipping fake eigenvalues (customPagePrimitives.jsx:290: `2.7/(i+1)`) as if they were RMT output is the single most disqualifying issue in either domain.
2. **Build the missing core PCA visualizations.** There is no biplot (PC1-vs-PC2 scores + loading vectors + cos2 coloring), no MP-density overlay (eigenvalue histogram vs theoretical Marchenko-Pastur pdf from q=T/N), no cumulative-variance axis, no dendrogram+heatmap clustergram, no efficient frontier with CAL/portfolio marker, no OU spread with entry/exit bands. `RenderOutput` (customPagePrimitives.jsx:438-446) collapses `timeline` and `clusterMap` to a flat `DataTable` and `frontier`/`scatter` to one generic scatter. For an eigenfactor product, missing biplot + MP overlay + clustergram is like a terminal with no price chart.
3. **Replace `TensorVisual` theater with real tensor readouts.** `TensorVisual` (customPagePrimitives(Search for tensor visual? customPagePrimitives.jsx:428-436) renders 36 decorative skewed divs with `opacity:(i*17)%70` — pure ornament on the two tensor sections (F05 tensor-core/factor, F08 tensor). 5. **Make the scree plot honest.** `StandardChart` scree branch (customPagePrimitives.jsx:289-305) synthesizes eigenvalues and draws MP as a flat red dashed `mp:0.42` line. A real scree needs: backend eigenvalues, MP upper-edge marker from actual q, Kaiser line at 1.0 (standardized), cumulative-% secondary axis, and selectable-k interaction wired to downstream books (F02 loadings, F06 k-sensitivity). 6. **Wire the dead controls.** Card copy/export buttons (customPagePrimitives.jsx:560-563) have `title` but no `onClick`. 7. **Bring inputs to ml-v2 parity.** `FieldControl` (customPagePrimitives.jsx:448-496) has no ticker autocomplete (ml-v2 has `TerminalTickerInput` with debounced search), booleans render as `true/false` string selects, holdings `textarea` (weights, bl_views, joint_shocks) has no JSON validation, number presets are unlabelled. ## Registry → primitives sync plan

PCA's registry (11 features, fields only) and `PCA_OUTPUT_BOOKS` (section taxonomy living inside customPagePrimitives.jsx:54-187) are currently two separate sources of truth, and neither is bound to data.

1. **Merge the taxonomy into one book.** Move `PCA_OUTPUT_BOOKS` out of the primitives file into a data module (or into registry.js per-feature as `outputs`), with each entry `{ id, title, source, dataKey, chartType, rank, fallbackKeys, config, xKey, yKeys, unit }`. Today `fallbackKeys` (e.g. customPagePrimitives.jsx:165) and `config` are declared and never read — implement `pickData` with fallback resolution (copy the ml-v2 `pickData` pattern) and delete entries with no backend key or mark them `researchOnly`.
2. **Renderer coverage matrix.** Distinct `chartType`s in use: `scree, composed, heatmap, metricDeck, table, line, bar, clusterMap, waterfall, pie, area, scatter, frontier, tensor, timeline`. Missing or aliased: `composed` (no composer — falls to generic line), `clusterMap`→table (wrong), `timeline`→table (wrong), `frontier`→scatter (wrong), `tensor`→ornament (wrong), `scree`→fake (wrong). Build: `ScreePlot` (real), `Biplot` (new), `Clustergram`, `FrontierChart`, `CumulativeWaterfall`, `TimelineEvents`, `TensorSlices` (or drop tensor sections).
3. **Delete `previewRows` from the render path.** Gate all synthetic data behind an explicit demo flag with a "DEMO DATA" badge; default path shows skeleton → error/empty. Remove hardcoded pie 72/28, flat MP 0.42, `2.7/(i+1)` eigenvalues, `T1..T72` labels in the same pass.
4. **Unify with ml-v2 primitives.** Ticker autocomplete, sortable tables, status badges, export modal, keyboard shortcuts, token palette — ml-v2 already built all of these. Extract shared components/tokens instead of maintaining a second amber-gradient design system. The Georgia/Inter vs Plex split must resolve to one system.
5. **Wire the dead controls.** Copy/export per card, run + params-hash header, fallback-key resolution, holdings JSON validation with weight-sum check, `aria-current` nav + focus management.
6. **Verification.** For each of the 11 books: bind one live API response, screenshot every primary section, assert no `previewRows` call in default path (grep CI check), keyboard-walk nav/cards/inputs, run axe on one workbench + home. Until that pass is green, badge every pca-v2 page "Prototype — demo data" so nobody mistakes sin() curves for eigenstructure.
