# Factors V2 Frontend Review — Brutal Pass

Scope (read-only): `frontend/src/components/factors-v2/customPagePrimitives.jsx` (3875 lines), `frontend/src/components/factors-v2/registry.js` (470), `frontend/src/components/factors-v2/FactorsV2Client.jsx` (594), `frontend/src/app/labs/factors-v2/page.js` (1491), `layout.js` (212), `feature-01..14/page.js` (38–117 each). Standard: Bloomberg Terminal / TradingView / QuantConnect.

## Score: 5.2 / 10

Functional depth is real (14 features, input contracts, research/realtime caps, annotation/drawing/export, command palette, split compare). Presentation layer drags it down: one 3875-line god-file, three competing design systems, SVG-everywhere charting with `lightweight-charts` installed but unused, fake-data visuals on the marketing page, silent table truncation, near-zero chart a11y. Shippable for internal labs, not allocator-facing.

## Top 10 improvements (ordered by impact)

1. **Split the god-file or it will own you.** `customPagePrimitives.jsx` holds ~50 components + ~800 lines of CSS-in-JS (`styles` string, ~3030–3875) + all chart/data/table/drawer logic. Every feature page imports all of it; no `next/dynamic`, no route-level code-split. Split into `charts/`, `tables/`, `forms/`, `drawers/`, `styles/` modules. Delete-or-merge `FactorsV2Client.jsx` (see 2). Impact: bundle, maintainability, crash radius.
2. **Kill one of the three design systems.** `FactorsV2Client.jsx:30-31` uses GitHub-dark `#0D1117` + blue `#2F81F7`; `customPagePrimitives.jsx:41-67` uses ATLAS amber `#F5A400` on `#0B0B0B`; `labs/factors-v2/page.js:32-46` uses a third amber/purple mix with its own `TOKENS`. Hub (`FactorsV2Client.FactorsV2Hub`) and labs home (`page.js`) are two homepages for the same 14 features. Pick ATLAS tokens, delete the other two paths, redirect. Impact: visual coherence, half the CSS bugs.
3. **Move time-series off recharts-SVG onto canvas.** 37 `ResponsiveContainer` instances, all SVG. `lightweight-charts` is in `frontend/package.json` but grep returns **zero** hits in factors-v2. 10Y daily percentile series (2520 pts, F01/F05), regime stacked areas (F04), annotated TS (420px, `AnnotatedTimeSeries`) all render thousands of SVG nodes. Add LTTB downsampling + canvas renderer for any series >500 pts; keep recharts only for small multiples (quintile bars, waterfall). Wire `Brush` (currently `StandardChart:1487`, `AnnotatedTimeSeries:~1660`, threshold `rows.length > 18/20`) to a single synced time-range, not per-chart local state. Impact: the only fix that makes 10Y histories usable.
4. **Stop lying with `monotone` + missing uncertainty.** `StandardChart:1483,1485` forces `type="monotone"` on IC decay (F05), equity curves (F07), capacity curves (F09). Smoothed splines invent persistence that half-life estimates then quote. Use `type="linear"` for IC/decay/equity; reserve monotone for regime probabilities. `ErrorBar:1412` only renders if `row.error` exists; F05 bootstrap CIs never map to a band (no `Area` CI envelope). Add CI band primitive and fail closed (no band = label "no CI"). Impact: credibility of every statistical claim.
5. **Give every chart a table + keyboard path.** Heatmap (`1118–1176`) is a `div` grid with `cells.find()` per cell (O(R*C*(R*C))), no `role="grid"`, cells not focusable, no arrow-key nav. Radar (`RadarVisual:1279`, `MultiFactorRadar:1880`), gauge (`Gauge:1092`, `MultiFactorGaugePanel:1515`), waterfall (`Waterfall:1294`) have `role="img"` + one flat `aria-label` and zero data alternative. Add: hidden-but-togglable `<table>` mirror per chart (reuse `DataTable`), `tabIndex=0` + arrow-key point navigation + `aria-live` value readout, CSV/TSV export already exists for tables (`copyRowsAsTsv:239`) so extend it to charts. Impact: a11y compliance + Bloomberg parity (every TV chart has data window).
6. **Fix silent data loss in tables.** `DataTable:1180` caps columns at 14, `:1192` slices rows at 500 with no notice. `MetricDeck:1059` slices to 8 cards. No pagination, no virtualization despite `@tanstack/react-virtual` in deps (zero usage in factors-v2). Add virtualized table (TanStack Virtual + sticky header), server-driven pagination contract, and an explicit "showing 500 of N — refine filters" banner. Never silently truncate allocator data. Impact: data integrity.
7. **Repair loading/empty/error as states, not afterthoughts.** `LoadingSection:2018` skeletons exist; `EmptySection:990-1006` renders `◌` / `✕` glyphs plus a debug leak (`available: a · b · c`, `:1006`). Error path is one `setError` string + toast (`run:2790-2792`), no per-section retry, no partial render. Add: per-card retry, stale-while-revalidate (show `previousData` with "stale" badge — state already exists `:2579`), empty states with next action ("adjust lookback", "load sample payload"), error states with request-id + constraint hint. Impact: trust during dormant-backend / slow-compute reality.
8. **Fix IA: URL is the state, not localStorage.** Form state lives in `useState` + `useDebounce 300ms (:2577)`; cross-page "live" strip reads `localStorage quant360:factors-v2:*:latest-summary` (`page.js:495-526`, `clusterStatus:611`). No `searchParams` sync, no deep-linkable section (`decorateSection:502` sets ids but nothing links to them), no shareable run. Registry `OUTPUT_LAYOUT` keys (`"valuation_gauges"`, `"spread_history"`, … `:422-436`) do not match page-manifest `dataKey`s (`"gauge_panel"`, `"percentile_series"`, …) — glued by `fallbackKeys` arrays. Canonicalize: registry `dataKey` = page `dataKey` = backend contract; sync form+outputs to URL; make `fallbackKeys` a migration shim with console warning, not a permanent feature. Impact: shareability, debuggability, backend-contract enforcement.
9. **Replace gauges with bullets + numbers.** `MultiFactorGaugePanel:1515-1579` renders N `mfg-card` boxes each with bar-track + sparkline + badge; `Gauge:1092-1116` is SVG arc; labs home `GaugeDial:730` is needle dial. Dials are chartjunk; Bloomberg shows percentile as band + numeric + delta. Replace with one sortable strip: factor | percentile band (30/70 markers already computed) | implied 12M | 1M delta | sparkline (real series, not `Sparkline:204-216` sine hash). Cap at 8 visible + "show all". Impact: removes the single most AI-slop visual in the product.
10. **Unify crosshair + time-axis semantics.** Hand-rolled `ChartSyncContext:129-156` broadcasts `activeLabel` on `onMouseMove` but only `StandardChart` line/area wires it (`:1448`); bar/scatter/heatmap/radar ignore it. X-axes are mixed (`inferKeys:330-336` guesses `date|time|year|month|horizon|aum|risk|vol|name|…`), so sync breaks across panels. Add: single time-scale primitive (shared domain, shared Brush, shared hover), numeric formatting per-axis (bps vs pct vs ratio — currently one `formatValue:97` for everything), log-scale only where valid (AUM sweep F09; never for IC). Impact: multi-panel pages stop feeling like 6 disconnected screenshots.

## Missing vs TradingView / Bloomberg (concrete)

- No linked crosshair / data-window across panels (TV: one hover moves all panes + price scale). Here sync is partial (see 10).
- No canvas depth: TV renders 10k+ candles with dataZoom; here 2520-pt series is SVG + per-chart Brush.
- No interval or scale discipline: TV has 1D/1W/1M + log toggle; here `logX` is an opt-in config flag, horizons are tokens, no shared time-granularity control.
- No symbol-first workflow: Bloomberg `FAC <GO>` starts from ticker; here ticker search (`TickerSearchInput:629`, `MultiTickerInput:781`) is buried inside per-feature forms with local fallback lists.
- No blotter/action bar: every insight (`generateInsight:1011`, `buildSectionInsight:445`) is prose; none emits an order-ticket-style action (set alert, export legs, pin to report). F14 report path is manual assembly.
- No quant essentials TV lacks but QuantConnect/Bloomberg have: IC time-series with rolling window + turnover overlay on same axis; quantile-spread (Q5-Q1) monitor; crowdedness velocity with half-life context. Registry computes these (F05/F06/F13) but UI shows them on separate cards with separate x-axes.
- Keyboard: TV/Bloomberg are fully keyboard-driven. Here j/k + f + 1-9 hijack (`:2753-2769`) with no help surface except `⌘K` dialog (`:2970-2991`, decorative `cmd-badge` in `layout.js:53`), no focus-visible rings on charts, no skip links.
