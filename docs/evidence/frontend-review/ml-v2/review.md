# ML-V2 Frontend Review — Brutal, Bloomberg-Grade

Scope (read-only): `frontend/src/components/ml-v2/customPagePrimitives.jsx` (1186 lines) + `frontend/src/components/ml-v2/registry.js` (2361 lines, 12 features) + `frontend/src/app/labs/ml-v2/` (index + 12 feature pages + layout strip).
Standard: Bloomberg Terminal / TradingView / QuantConnect. Best-in-class refs: MLflow, Weights & Biases, shap/shapash, Evidence.dev.

## Score: 5.5 / 10

Why not lower: this is the only one of the two domains that is actually wired to data. `runMlV2Feature` + form state + per-section `pickData` + export modal + ticker autocomplete + keyboard nav + cinema focus + reorderable dock is a real workbench skeleton. Why not higher: the renderer layer collapses ~15 distinct registry renderers into ~8 generic buckets, so the most differentiated outputs (beeswarm, waterfall, dendrogram, calibration, stacked-area regimes, error bars) all render as the wrong chart. Plus dead CSS, fake progress, and a11y holes keep it below professional terminal grade.

## Top 10 improvements by impact

1. **Build the missing renderers instead of collapsing to line charts.** `renderSection` (customPagePrimitives.jsx:573-585) maps everything unknown to `LineLikeChart`. Registry needs: `stacked_area` (regime probabilities F06), `beeswarm` (F02 shap_beeswarm_proxy), `waterfall` (F02/F11 — currently forced through `BarLikeChart horizontal`, losing cumulative connectors), `dendrogram` (F05 cluster_dendrograms — currently falls to line chart, completely wrong), `calibration` (F07 prediction_calibration_curve), `band`/`band_line` (F03 confidence intervals, F07 uncertainty), `error_bar_table` (F11 causal_ape_leaderboard — CIs are the whole point), `timeline`/`event_log` (F04 barrier hits, F07 pruning log, F08 IC decay alerts), `rank_table`/`comparison`/`policy_table`. Each wrong-viz output is a trust-destroying bug, not a cosmetic gap.
2. **Replace `inferKeys` regex-guessing with an explicit contract.** customPagePrimitives.jsx:110-116 picks x/y keys by regex over the first row. On IC tables, APE tables, and tournament tables this silently picks the wrong axis. Registry `getMlV2Sections` (registry.js:2349-2361) already builds sections — extend each output with `{ xKey, yKeys, errorKeys }` or a per-renderer default map, and pass through `section.config`. No guessing at render time.
3. **Give charts a terminal-grade interaction layer.** All charts are fixed 380px (customPagePrimitives.jsx:354,375,449), no `Brush`, no synced crosshair, no log scale, no range zoom. Steal TradingView: brush + minimap on `backtest_paths_chart` / `spread_zscore_timeseries` / `rolling_monthly_ic_series`; sync tooltips across the IC/weight/decay triple on F02/F08. Fixed heights also break density — make height a function of dock state and viewport.
4. **Fix the heatmap palette split.** `MLHeatmap` (customPagePrimitives.jsx:428) hardcodes cyan `rgba(0,212,255,…)` and magenta while `TOKENS.signal` is `#FF8A1E` orange and `TOKENS.pos` is `#2BA85E` green. The table heat-tint (customPagePrimitives.jsx:292-293) uses a third palette (`#FF4D6A`/`#00E5A0`). One asset, three color languages. Unify on TOKENS, add a colorblind-safe diverging option, and surface the scale with tick values instead of only min/max.
5. **Stop faking progress.** `run()` (customPagePrimitives.jsx:849-868) runs `setInterval(+0.07/280ms)` — a fake percentage bar — while `.ml-run-progress` (customPagePrimitives.jsx:953-959) and `.ml-sticky-summary` (customPagePrimitives.jsx:960) both stick at `top:52px` and z-fight. Replace with honest indeterminate state + stage labels from the API (`purging → fitting → attributing`), and offset the two sticky bars (52px / 88px).
6. **Repair the input contract.** `FieldInput` (customPagePrimitives.jsx:153-196): `integer`/`float`/`select` all render `<select>` from `options` only — so `profit_taking_barrier: 0.05` / `entry_z: 2.0` / `number_of_trials` (no options) render as dead single-option selects. `boolean` (`rl_rebalancing`, `higher_order_interactions`, F08 flags) falls through to a free-text input. `forgetting_factor` has `range:[0.9,1.0]` in registry but no slider. Fix: number inputs with min/max/step from registry, switch controls for booleans, slider for ranged floats, validation messages per field.
7. **Make the ticker input keyboard-complete and valid HTML.** `TerminalTickerInput` (customPagePrimitives.jsx:198-264): suggestion menu is a `<div>` inside a `<label>`, no `role=listbox/option`, no arrow-key navigation, no Escape/blur close, `toUpperCase()` on every keystroke breaks IME composition. Add listbox semantics, arrow+Enter+Escape, `aria-expanded/activedescendant`, and move the menu out of the label.
8. **Close the a11y gaps that block keyboard/screen-reader traders.** Sortable `<th onClick>` (customPagePrimitives.jsx:286) has no `role=button`, `tabIndex`, or `aria-sort`; dock drag-reorder (customPagePrimitives.jsx:720-729) has no keyboard alternative; annotation canvas (customPagePrimitives.jsx:603-646) is pointer-only; single-key shortcuts (`f`, arrows, customPagePrimitives.jsx:870-883) hijack screen-reader quick-nav with no help modal and no opt-out; `motion.article` blur-fade on every card (customPagePrimitives.jsx:739) ignores `prefers-reduced-motion`. Fix all six; they are cheap and each is a Bloomberg-bar failure.
9. **Delete the dead code and the render-blocking font import.** `@import` Google Fonts inside `ML_STYLES` (customPagePrimitives.jsx:930) blocks render and risks CSP failure — use `next/font` or a `<link>`. Dead styles: `.ml-quadrant` v1 (customPagePrimitives.jsx:1108-1118), `.ml-metric-v3` family (customPagePrimitives.jsx:1072-1083), `.ml-empty-v3` (customPagePrimitives.jsx:1122-1125), `.ml-run-v3`/`.hero-v3` leftovers — none are rendered by `renderSection`. `Quadrant` uses `preserveAspectRatio="none"` (customPagePrimitives.jsx:472) which distorts the DSR/PBO geometry, plus 3.2px/2.6px SVG text nobody can read. Either finish or delete.
10. **Finish the run lifecycle: skeletons, per-card errors, localStorage round-trip.** `MLEmpty` (customPagePrimitives.jsx:563-571) has custom copy for only 3 of ~180 outputs; everything else gets "Configure inputs and run". `run()` writes `localStorage quant360:ml-v2:{id}:latest` (customPagePrimitives.jsx:859) but nothing ever reads it — the home page (customPagePrimitives.jsx:906-927) shows no last-run state, no search, no status. Add per-card skeleton + error boundary + retry, read back last-run summary on mount, and give the home grid a filter + status column. Also fix TSV export escaping (customPagePrimitives.jsx:777-782 joins raw values — tabs/newlines corrupt Excel paste).

## Registry → primitives sync plan

The registry is the source of truth (12 features, ~180 outputs with `key/location/renderer/status`); primitives implement ~8 buckets. Sync in this order:

1. **Renderer coverage matrix (do first).** Enumerate every distinct `renderer` string in registry.js (`histogram, comparison_bar, metric_panel, line_bundle, line_or_table, line, quadrant, table, rank_table, bar, beeswarm, waterfall, heatmap, metric_table, scatter_or_line, band, macro_overlay, stacked_area, curve, surface_or_heatmap, network, dendrogram, comparison, grouped_bar, calibration, band_line, event_log, error_bar_table, timeline, path_table, horizontal_bar, line_or_table, policy_table, network_summary, live_fast_score…`). For each: `implemented | aliased-wrong | missing`. Aliased-wrong (beeswarm→scatter, dendrogram→line, stacked_area→line, calibration→line, error_bar→table) are P0 bugs.
2. **New primitive components (one per missing family).** `StackedAreaChart`, `BeeswarmStrip`, `WaterfallChart` (cumulative), `DendrogramView`, `CalibrationCurve`, `BandChart` (CI), `ErrorBarTable`, `EventLog`, `TimelineView`, `RankTable`, `ComparisonView`. Each takes an explicit data contract; no `inferKeys` inside.
3. **Section contract upgrade.** Extend `getMlV2Sections` (registry.js:2349-2361) to pass through `{ xKey, yKeys, errorKeys, unit, status, description }` from registry output entries (add those fields to registry entries where missing) instead of `{config:{}}` always-empty. `renderSection` dispatches on `(renderer, location)` pair, not substring matching.
4. **Status legend + enforcement.** Registry statuses (`live, live_proxy, live_importance_proxy, live_capped, live_fast_grid, live_diagnostic, live_if_arch_installed, research_proxy…`) currently collapse to a tiny `StatusBadge` (customPagePrimitives.jsx:686-690) with only 3 labels mapped. Build a legend row + per-card badge with the full vocabulary, and gate `research_proxy` outputs behind an explicit "research proxy" treatment instead of rendering them identically to live.
5. **Field-type parity.** Registry field types (`ticker_list, ticker, select, integer, float, multi_select, boolean, number` + `range` + `presets`) must each have exactly one `FieldInput` branch with validation. Today `boolean`/`number`-without-options/`range` have none. Add and snapshot-test every branch.
6. **Delete dead styles + fix tokens.** Remove unreachable CSS (`.ml-quadrant` v1, `.ml-metric-v3`, `.ml-empty-v3`, `.ml-run-v3`, `.hero-v3` leftovers), move fonts to `next/font`, unify heat palettes on TOKENS, fix `preserveAspectRatio` on Quadrant or replace it with the DSR/PBO two-panel card.
7. **Verification.** For each of the 12 features: run once against live API, screenshot every primary-ranked section, assert renderer branch hit (log unmapped renderers to console in dev), keyboard-walk the dock/cards/modal, run axe on one workbench page + home.
